# Support

## Where to ask

- **Bug:** open a GitHub issue using the bug report template.
- **Feature request:** open a GitHub issue using the feature template.
- **Security issue:** follow [SECURITY.md](SECURITY.md), not a public issue.
- **Questions:** use GitHub Discussions when enabled for the repository.

## Before opening an issue

Please include:

- NovaFetch version.
- Android version and device model.
- Whether the issue occurs on Debug or Release.
- The relevant URL/platform, if safe to share.
- Steps to reproduce.
- Expected behavior.
- Actual behavior.
- Relevant log output with personal data, cookies, tokens, and private URLs removed.

Do not upload `cookies.txt`, authentication tokens, private media, or other sensitive data.
