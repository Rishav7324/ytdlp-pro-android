# Changelog

All notable changes to Zyvro are documented here.

The project follows a release-oriented changelog. Development changes may land before a version is published.

## [Unreleased]

### Added

- Zyvro rebrand (app name, `com.zyvro.app` applicationId, v3.0.0 line).
- New Zyvro adaptive launcher icon with monochrome themed-icon support.
- CI-only release signing via GitHub Secrets with local debug-key fallback.
- Minimal clean Material3 UI refresh pass (reduced glass effects).

### Changed

- Legacy NovaFetch launcher assets removed.
- Open-source project documentation and contribution standards.
- GPL-3.0-or-later licensing metadata.
- Security, support, code-of-conduct, issue, and pull-request guidance.
- Expanded audio/video playback controls.
- Improved format and quality selection.
- Improved Android release build configuration and R8 compatibility.
- Refreshed repository documentation and project architecture description.

## [3.0.0]

Zyvro rebrand line: new app name, new icon, `com.zyvro.app` package (fresh install; Play listing treated as a new app).

## [2.0.0]

Initial Zyvro production-upgrade line.
