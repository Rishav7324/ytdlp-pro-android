# Code of Conduct

## Our standard

NovaFetch is an open-source project and we want it to be a respectful, constructive place for contributors of all experience levels.

Participants are expected to:

- Be respectful and professional.
- Give and receive constructive feedback.
- Focus criticism on ideas and code, not people.
- Welcome different viewpoints and experience levels.
- Avoid harassment, discrimination, personal attacks, trolling, and unwanted contact.

## Enforcement

Project maintainers may remove or edit contributions that violate these standards and may restrict participation when necessary to keep the project safe and constructive.

Report serious or private concerns through the process in [SECURITY.md](SECURITY.md) or contact the maintainer through the repository's GitHub profile.

## Scope

This code of conduct applies to project spaces, issues, pull requests, discussions, and other project-related interactions.
